# 【タスク1/6】アンケート管理者を個人単位のみに変更

対象範囲：アンケート作成・複製・編集機能（Java Spring / Next.js）

## 背景・要件
現状、設定タブの権限管理は「個人単位」「部署単位」の両方から選択できる仕様になっているが、これを**個人単位のみ**に変更する。

## 実装内容
- 画面から部署選択のチェックボックスを完全に削除し、**名前検索して追加するUIのみ**に変更する
- 不要になったバックエンドリソースをすべて削除する
  - `adminDeptIds`（部署ID関連のフィールド・パラメータ）
  - アンケート管理部署テーブル、および関連するDAO/Entity
  - 上記に紐づく不要なService/DAOメソッド（自動生成コードを除く）
  - **上記以外にも部署単位管理に伴って不要になったコードがあれば漏れなく調査・削除すること**
- SQLの初期化データ（イニシャライズ用SQL）も、部署単位管理を前提とした内容を削除・更新する
- 必要なDAOメソッド（自動生成以外）・Serviceメソッドについて、既存の他機能の単体テストと同水準の単体テストを実装する
- テストを実行し、成功することを確認する

## 完了確認チェックリスト
- [ ] アンケート管理者設定が個人単位（名前検索）のみになっており、部署単位の選択仕様・UI・コードが残っていない
- [ ] `adminDeptIds`やアンケート管理部署テーブルなど、不要になったリソースが完全に削除されている
- [ ] SQLイニシャライズが新仕様に合わせて更新されている
- [ ] 追加した単体テストが実行され、すべて成功している
