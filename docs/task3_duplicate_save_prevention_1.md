# 【タスク3/6】重複作成・二重更新の防止確認

対象範囲：アンケート作成・複製・編集機能（Java Spring / Next.js）
（前提：タスク1・2は対応済みです）

### ⚠️ 着手前の注意事項
開発は一部中途半端に進んでいる可能性があります。着手前に現状の実装状況を確認し、

## 懸念点
アンケート作成・複製・下書き編集の画面では、確認画面を除く画面遷移やブラウザクローズ時に下書きとして自動で一時保存される仕様になっている（実装済みの想定）。一方で、一時保存ボタンをクリックした場合もダッシュボードへの画面遷移を伴うため、**自動保存と手動一時保存が両方走り、二重保存・二重更新が発生しないか**を確認する必要がある。

## 確認・対策内容
- 一時保存ボタン押下による保存処理と、画面離脱時の自動保存処理が同時に走らないよう排他制御・フラグ管理などの対策がされているか確認する
- 対策がされていない場合は、二重保存・二重更新が発生しないように実装を修正する
- 下書き編集画面における一時保存についても同様に、二重更新（楽観ロックエラーなど）が発生しないか確認・対策する

## 完了確認チェックリスト
- [ ] 新規登録画面で一時保存を押すとDBに保存される（作成途中のデータでも可）、かつ`sessionStorage`が破棄される
- [ ] 確認画面を除く画面遷移・ブラウザクローズ時に、下書きデータが自動でDB保存され`sessionStorage`が破棄される
- [ ] 一時保存操作（画面遷移を伴う）と自動保存が競合せず、下書き保存が二重実行されない
- [ ] 下書き編集画面で一時保存を押すとDBデータが更新される（ステータス`draft`）
- [ ] 下書き編集画面で確認画面を除く画面離脱をした際、DBデータが更新される
- [ ] 一時保存に伴う画面離脱と自動保存が競合せず、二重更新や楽観ロックエラーが発生しない
- [ ] 悲観ロックに加え、`version`を用いた楽観ロックが実装されている（必須）
