# 【タスク6/6】総合レビュー・抜け漏れ洗い出し・その他確認事項

対象範囲：アンケート作成・複製・編集機能（Java Spring / Next.js）
（前提：タスク1〜5はすべて対応済みです）

---

## 1. 総合レビュー（タスク1〜5の横断確認）

これまで個別に実装・確認してきた内容について、機能全体を通しで動かし、矛盾や連携漏れがないか確認してください。

- [ ] 新規登録ボタン押下時は画面遷移のみでDBには格納されない
- [ ] ログインIDやアンケート作成関連のダミーデータが完全に削除されている
- [ ] 作成〜確認画面への遷移はDB保存せず`sessionStorage`でデータ管理されている
- [ ] 修正ボタン押下時、`sessionStorage`経由でデータが渡っている
- [ ] 確認画面でサンクスメッセージ入力後、作成を押すとステータス`created`でDB保存される
- [ ] 作成・複製・編集の一連の流れ（作成→確認→作成完了、複製→確認→作成完了、編集→確認→更新完了）を通しで実行し、途中でエラーやデータ不整合が起きないことを確認する

## 2. 抜け漏れの洗い出し

タスク1〜5、および上記1のチェックリストでは網羅しきれていない観点が他にもある可能性があります。

- 本依頼の対象範囲（アンケート作成・複製・編集機能）について、これまでのチェックリストに含まれていない観点・エッジケース・リスクを自ら洗い出す
  - 例：同時編集・同時アクセス時の挙動、セッション切れ/認証切れ時の挙動、通信エラーやAPI失敗時のリトライ・エラーハンドリング、入力バリデーション（文字数上限、必須項目、不正値）、管理者0人での保存可否、タイトル重複時の挙動、ブラウザバック・リロード時の挙動、複数タブでの同時操作、権限のないユーザーによる不正アクセス、`sessionStorage`のデータ改ざん・不整合時の挙動　など（あくまで例であり、実際のコードとドキュメントを踏まえて洗い出すこと）
- 洗い出した項目について、それぞれ現状の実装が対応できているか確認する
- 対応できていない項目があれば、対応の要否・優先度を含めて報告し、必要に応じて実装・修正を行う
- 最終的に、**洗い出した項目一覧とその確認結果（対応済み／要対応／対応不要とその理由）**を報告してください

## 3. その他の確認事項

- **ドキュメント整合性**：`docs`配下の各ドキュメントを、現在の実装内容にすべて漏れなく反映・更新する
- **ダミーデータ全体確認**：対象範囲以外の機能も含め、バックエンド・フロントエンド全体でログイン情報や表示データにモック/ダミーデータが残っていないか確認する
- **デプロイ前構成確認**：localhostのURLのハードコーディングなど、デプロイ時に問題となる設定が残っていないか確認する
- **非機能要件の確認**：性能・セキュリティ・可用性など、プロジェクトで定義されている非機能要件を満たしているか確認する

## 依頼したいこと
上記1〜3を実施し、結果を報告してください。これでアンケート作成・複製・編集機能の一連の対応は完了です。
