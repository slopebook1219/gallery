# 【タスク7/7】結合テストシナリオの作成・実行

対象範囲：アンケート作成・複製・編集機能（Java Spring / Next.js）
（前提：タスク1〜6はすべて対応済みです）

### ⚠️ 実施時の注意事項
これまでの単体・機能単位の確認とは別に、**ログインから一連の操作を通しで行う結合テスト**を実施してください。実際のユーザー操作の流れを再現し、機能同士の連携部分（画面遷移、DB反映、`sessionStorage`、ロック、モーダル表示など）に不整合がないかを確認することが目的です。

実行方法は既存のE2Eテスト環境（あれば）を利用し、なければ手動での動作確認でも構いません。プロジェクトの実行環境に合わせて判断してください。

---

## 結合テストシナリオ

以下の各シナリオについて、手順通りに実施し、期待結果と一致するか確認してください。ズレがあれば原因を特定し、修正してください。

### シナリオ1：新規作成〜公開予定作成までの一連の流れ
1. ログインする
2. ダッシュボードから新規登録ボタンを押す（この時点でDBに未格納であることを確認）
3. タイトル・問題・選択肢・管理者（個人検索で追加）・公開期間などを入力する
4. 一時保存を押す → DBに下書きとして保存され、`sessionStorage`が破棄されることを確認
5. 再度該当アンケートを下書き編集で開く（バックエンドへのGETリクエストにより最新のDBデータが取得され、編集画面の初期状態として反映されることを確認）
6. 確認画面に遷移する（DB未更新、`sessionStorage`で管理されていることを確認）
7. サンクスメッセージを入力し、作成を押す → ステータス`created`でDB保存、`sessionStorage`破棄を確認

### シナリオ2：下書きからの複製
1. ログインする
2. ダッシュボードで下書きアンケートの複製ボタンを押す
3. タイトル編集モーダルで「複製元のタイトル_コピー」を編集する
4. 複製作成画面に遷移し、編集後のタイトルと公開期間以外のデータが引き継がれていることを確認する
5. 作成まで完了させ、DBに新規アンケートとして保存されることを確認する

### シナリオ3：公開予定からの複製
1. ログインする
2. ダッシュボードで公開予定アンケートの複製ボタンを押す
3. モーダルを介さず「〇〇_コピー」の形でタイトルが自動初期化され、複製作成画面に引き継がれることを確認する
4. 作成まで完了させ、DBに新規アンケートとして保存されることを確認する

### シナリオ4：下書き編集中の画面離脱（自動保存）
1. ログインする
2. 下書きアンケートの編集画面を開き、内容を変更する
3. 確認画面を経由せずに別画面へ遷移する（例：ブラウザバック、他メニューのクリック）
4. ステータス`draft`でDBが更新され、`sessionStorage`が破棄されていることを確認する
5. 一時保存ボタンを押した場合も、画面遷移と自動保存が競合して二重保存にならないことを確認する

### シナリオ5：公開予定編集中の画面離脱（モーダル確認）
1. ログインする
2. 公開予定アンケートの編集画面を開き、内容を変更する
3. 別画面へ遷移しようとする → 「保存されていない変更があります」モーダルが表示されることを確認する
4. モーダルで離脱を選択した場合、変更が破棄されDBが更新されないことを確認する
5. 確認画面についても同様に、画面遷移時にモーダルが表示されることを確認する
6. ブラウザを閉じた場合、変更が破棄され`sessionStorage`が削除されることを確認する

### シナリオ6：編集ロックの競合（2ユーザーでの操作）
1. ユーザーAでログインし、あるアンケートの編集画面を開く（ロック取得を確認）
2. 別ブラウザ・別セッションでユーザーBとしてログインする
3. ユーザーBがダッシュボードから同じアンケートの編集ボタンを押す → 「誰かが編集中です」モーダルが表示されることを確認する
4. ユーザーBが同アンケートの削除ボタンを押す → 同様にモーダルが表示されることを確認する
5. ユーザーAが更新を完了する → データが上書きされ、`sessionStorage`が破棄され、ロックが解放されることを確認する
6. ロック解放後、ユーザーBが編集画面を開けることを確認する

### シナリオ7：管理者削除を伴う編集更新
1. ログインする
2. 既存アンケートの編集画面を開き、管理者を1名削除する
3. 更新を完了する
4. DB上で該当管理者レコードが物理削除ではなく`delete_flag`によって管理されていることを確認する

## 依頼したいこと
上記シナリオ1〜7を実施し、各手順の期待結果と実際の挙動を照合してください。不一致があれば原因を修正し、再度該当シナリオを実施して問題が解消したことを確認してください。最終的に、**各シナリオの実施結果（OK/NG、NGの場合は原因と対応内容）を一覧で報告してください。**
